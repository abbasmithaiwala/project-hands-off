# 1. Record architecture decisions

Date: 2026-11-14
Status: Accepted

## Context
The project makes several non-obvious technical choices (detector, API style, licensing) that future contributors need to understand.

## Decision
Record each significant decision as a short ADR in `docs/adr/`, numbered sequentially, with context, decision and consequences.

## Consequences
Decisions and their reasons stay discoverable. Superseded decisions are marked as such rather than deleted.
